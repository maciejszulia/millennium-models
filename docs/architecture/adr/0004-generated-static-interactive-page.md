# ADR 0004: Generated static interactive page

## Status

Accepted (commit `d39d3c9`).

## Context

Readers should explore the figures (hover values, rotate 3D surfaces, move time sliders) without installing Python. GitHub Pages serves static files only.

## Decision

`interactive.py` builds the plotly figures in Python and writes one file, `docs/index.html`, from an HTML template. The page loads plotly.js from `cdn.plot.ly` with the version reported by the installed plotly package (`get_plotlyjs_version()`) and MathJax 3.2.2 from jsDelivr. The generated file is committed and served at `maciejszulia.github.io/millennium-models`.

## Consequences

- Positive: no server and no build step on the hosting side.
- Positive: the plotly.js version always matches the Python package that produced the figure data.
- Negative: the page needs network access to two CDNs and WebGL for the 3D figures.
- Negative: the committed HTML must be regenerated by hand after a change to the numbers.

## Evidence

- `interactive.py`: `OUT = Path(__file__).parent / "docs" / "index.html"`, the `<script src=...>` lines of the template, `get_plotlyjs_version()`.
- README, "Rysunki interaktywne".
